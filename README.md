## 📖 Project Overview

This repository is a collection of practical implementations developed as part of the Operating Systems coursework. It focuses on understanding how operating systems manage processes, CPU execution, concurrent operations, system resources, and memory.

Each practical assignment translates theoretical concepts into working C++ programs, helping develop a deeper understanding of operating system mechanisms and algorithmic problem-solving.

## 🗂️ Practical Assignment Roadmap

The repository contains five practical implementations covering different areas of Operating Systems.

### 01 — AI Task Scheduler

**Concept:** CPU Scheduling

Implementation of an AI Task Scheduler using multiple CPU scheduling algorithms to understand process execution, scheduling order, and CPU utilization.

### 02 — Multithreaded Student Performance Processing

**Concept:** Multithreading and Concurrency

A multithreaded program that processes student performance data using concurrent execution to understand thread-based processing and performance.

### 03 — Concurrent Banking System with Synchronization

**Concept:** Process Synchronization

Implementation of a concurrent banking system that demonstrates synchronization mechanisms and safe access to shared resources.

### 04 — Banker's Algorithm

**Concept:** Deadlock Avoidance

Implementation of Banker's Algorithm to analyze resource allocation, identify safe states, and avoid deadlock conditions.

### 05 — Virtual Memory and Page Replacement Simulator

**Concept:** Memory Management

Implementation of a virtual memory simulator that demonstrates three major page replacement algorithms:

- FIFO – First-In First-Out
- LRU – Least Recently Used
- Optimal Page Replacement

The simulator evaluates page hits, page faults, hit ratios, and fault ratios using different page-reference strings and physical memory frames.

## 💻 Run the Programs Locally

### Requirements

- Windows / Linux operating system
- GCC or MinGW C++ compiler
- Visual Studio Code or another C++ IDE
- Git

### Step 1 — Clone the Repository

```bash
git clone https://github.com/ahertejal/OperatingSystem-OS-_Assignments.git
```

### Step 2 — Open the Repository

```bash
cd OperatingSystem-OS-_Assignments
```

### Step 3 — Compile an Assignment

Example: Assignment 05

```bash
g++ Assignment05.cpp -o Assignment05
```

### Step 4 — Execute

**Windows:**

```bash
.\Assignment05.exe
```

**Linux / macOS:**

```bash
./Assignment05
```

To execute another assignment, replace the filename with its corresponding source file.
